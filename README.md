# Calculator

A simple desktop calculator with a clean dark design and easy-to-use layout.

## Overview

This calculator is built for quick everyday math tasks. It includes the standard arithmetic operations, clear buttons, and keyboard support for faster input.

## Features

- Addition, subtraction, multiplication, and division
- Clear and clear-entry controls
- Decimal support
- Keyboard input support
- Modern dark interface
- Windows desktop app style

## How it works

The app displays the current expression and updates as numbers and operators are entered. Pressing equals calculates the result and shows it on the screen.

## Files

- `calculator_app.exe` - main calculator application
- `README.md` - project information

## Notes

The app is ready to use as a desktop program and is designed to feel simple and familiar, similar to a standard calculator.
